Support

From download to first capture.

CursorPocket installs for your Windows account and includes everything it needs. No developer mode, separate .NET installation, or administrator password is required.

Install

  1. Download CursorPocket-Setup-x64.exe.
  2. Open the installer. On a first install, Windows may show “Windows protected your PC.” Follow the SmartScreen steps below.
  3. Choose whether to add a desktop shortcut, then select Install.
  4. Follow the three-step welcome tour and try command mode once.

Requirements: Windows 10 version 2004 or newer, Windows 11, and an x64 processor.

First-install warning

When Windows shows only “Don’t run”

1

Select More info.Windows deliberately hides the second action on the first screen. Do not select Don’t run if you intend to continue.

2

Check the source, then select Run anyway.Continue only if you downloaded CursorPocket-Setup-x64.exe from this project’s GitHub Release. Verify the SHA-256 below when in doubt.

If “Run anyway” still does not appear: Smart App Control or an organization policy is blocking unsigned apps on that PC. CursorPocket cannot safely override that setting. Do not disable Windows security or install a certificate; use an unmanaged personal PC, or ask the device administrator to approve the app.

Verify a download

Each release includes SHA256SUMS.txt. In PowerShell, run Get-FileHash .\CursorPocket-Setup-x64.exe -Algorithm SHA256 and compare the result with the release file before opening the installer.

Why Windows shows the warning

CursorPocket installers are currently unsigned so this free open-source project needs no paid signing service. Windows therefore starts each release with no publisher reputation and may identify it as Unknown publisher. Signing future releases consistently, or publishing through the Microsoft Store, is the long-term way to reduce or remove this interruption.

If you installed a build before 0.4.1, download and install 0.4.1 manually once. Those early builds require the former signing publisher and cannot install the first unsigned release automatically; updates after 0.4.1 are automatic.

Open CursorPocket

CursorPocket normally stays in the notification area. Press Ctrl+Shift+Space, use the tray icon, draw two quick mouse circles, or hold both mouse buttons to open command mode. All activation methods can be changed in Settings.

Annotate a screenshot

Take a screenshot and CursorPocket copies it to the clipboard, then opens the full-resolution annotation editor. Use the visible tools to draw, highlight, add arrows, shapes, text, and numbered steps. You can also crop, cut, add a flat backdrop, redact content, read text locally with Windows OCR, or pin the image above another window.

Press Ctrl+Z to undo and Enter to save. Escape first returns an active drawing tool to Select, then closes the editor; your original screenshot is never lost. Crop, cut, and backdrop create a new capture instead of replacing the original.

Record a video walkthrough

Open command mode and press V. In preflight, choose a display, region, or window; confirm the named microphone and camera; then set pointer visibility, frame rate, and countdown. Nothing records until you select Start recording.

While recording, the red HUD shows time, audio activity, and active devices. Select Stop and save, or press Escape, to finish the local MP4. The command panel and HUD are excluded from the saved video. With a display or region source, the optional camera self-view appears where you place it and is included in the recording.

Use the Library

Open command mode and press O. Filter by screenshots, video, audio, text, or links; select one or many items; and use the large preview to inspect or play what you saved. Video and audio include seek, volume, playback speed, repeat, skip, and full-window controls.

Use ↑ and ↓ to move, Enter to open, Space to play or pause, Ctrl+R to reveal the file, and Ctrl+C to copy its path. Delete moves selected captures to the Recycle Bin so removal remains recoverable.

Camera or microphone unavailable

Close other apps using the device, then retry. Check Windows Settings → Privacy & security → Camera or Microphone and allow desktop apps. Screen recording remains available if the camera fails.

Updates

CursorPocket checks one static GitHub release file at most daily when automatic checks are enabled. It will ask before downloading or installing. Use Settings → Updates → Check now for a manual check. Updates wait until recording, capture, and annotation work is finished.

Release notes

See the changes and known details for every version on GitHub Releases.

Uninstall or reinstall

Use Windows Settings → Apps → Installed apps → CursorPocket → Uninstall. Captures are kept. Reinstalling or updating preserves settings and the capture Library.

Report a problem

Search or open an issue in GitHub Issues. Include your Windows version, CursorPocket version from Settings, display scale, and exact steps. Do not attach private captures or logs without reviewing them first.
